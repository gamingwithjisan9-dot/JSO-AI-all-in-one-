# JSO Labs — Render Ready

This repository contains three apps that can be deployed from the same GitHub repository on Render.

## Apps

- `jso-landing-page` — static HTML/CSS/JavaScript landing page
- `jso-ai-seo-audit` — Python Flask SEO audit application
- `ai-chat-studio` — Node.js/Express AI chat, image and file/PDF app

## Render deployment

The root `render.yaml` is a Render Blueprint for all three services. You can also create the services manually and set each Root Directory to its app folder.

Expected service URLs after deployment:

- Landing: `https://jso-landing-page.onrender.com`
- SEO Audit: `https://jso-ai-seo-audit.onrender.com`
- Chat Studio: `https://ai-chat-studio.onrender.com`

Render may require a different available service name, so update `jso-landing-page/config.js` if a URL changes.

## Important environment variables

### SEO Audit

- `FLASK_SECRET_KEY` — generated by Render in the Blueprint
- `DATABASE_PATH` — `jso_ai.db` for demo use
- `OPENAI_API_KEY` — add your own API key if you want optional AI enhancement
- `OPENAI_MODEL` — model identifier available to your API account

Do not commit API keys or `.env` files to GitHub.

## Important production note

The SEO audit app currently uses SQLite. It is suitable for a demo, but persistent production data should be moved to a managed PostgreSQL database/storage strategy.

## Local commands

### Flask

```bash
pip install -r jso-ai-seo-audit/requirements.txt
python jso-ai-seo-audit/app.py
```

### Node

```bash
cd ai-chat-studio
npm install
npm start
```

The landing page can be opened directly from `jso-landing-page/index.html`.
